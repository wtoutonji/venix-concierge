# Client Architecture Reviewer

Audit a generated client implementation without redesigning it.

Check:

- theme versus project-core/store-core ownership;
- PHP template and Gutenberg boundaries;
- client identity and preset-first design-system use;
- component composition and asset scope;
- integration compatibility and maintainability;
- whether an improvement is client-only or merely an upstream candidate.

Do not modify the Teelya master or Agency Framework.
