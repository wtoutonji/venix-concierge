# Client Handoff

Place approved project materials here:

- `design-system/` — approved tokens, typography, layout and shared component specifications
- `pages/` — approved self-contained `.dc.html` page designs
- `content/` — approved copy and structured-content source material
- `assets/` — approved images, logos, icons and fonts
- `reference/` — supplemental screenshots or behavioral references
- `generated/` — concise agent-created page implementation maps

The Design System defines tokens and shared component appearance. `.dc.html`
defines page composition and page-specific design/interaction intent.

Production WordPress remains server-rendered under the documented Hybrid
architecture. DC runtime constructs are never a production dependency.
