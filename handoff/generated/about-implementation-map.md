# About implementation map

Source: `handoff/pages/about.dc.html`. Status: first production implementation. The approved EN/PL defaults remain theme-owned (`inc/content/about.php`) and are the fallback; About text (55 fields across Hero, Our Story, Purpose/Mission/Vision, How We Work, Values, International Service, Final CTA) and its three image slots (`about.hero`, `about.story`, `about.culture`) are now overridable per page and per language through the Venix Page Content meta box (see `site-implementation-map.md` → Editable page content). Fixed: layout, card/step counts and order, step numbers, "Value 0X" ordinals, the decorative rule and the CTA destination. Polish source copy remains in the approved handoff; Polylang owns production language URLs, document language and translations. No second language mechanism or invented Polish translation is implemented.

About page routing uses `venix_concierge_is_about_page()`. It first recognises the canonical `about` page slug; when Polylang is active, it resolves the queried page's server-side translation IDs with `pll_get_post_translations()` and recognises the page when any translation is the canonical `about` page. This keeps translated About slugs on the same template and conditional stylesheet without hardcoding a language-specific slug. Without Polylang, the canonical English slug remains the safe fallback.

SEO record: **About Venix Concierge | Luxury Chauffeur Service Warsaw**. Description: **Venix Concierge — a Warsaw-based chauffeur and concierge company operating since 2024. Built on precision, privacy and personal care.** No project SEO integration currently exists, so these values are recorded rather than injected through a competing framework.
