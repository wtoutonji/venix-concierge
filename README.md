## Local development

1. Copy or edit `PROJECT-ENV.example.md` as `PROJECT-ENV.md`.
2. Configure `PHP_PATH`, optional `WP_CLI_PATH`, `WP_ROOT` and `LOCAL_URL`.
3. Connect the theme and plugins to LocalWP as described in `docs/LOCALWP.md`.
4. Before WP-CLI mutation, verify `wp option get home` exactly equals `LOCAL_URL`.
