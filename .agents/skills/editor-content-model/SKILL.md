# Editor and Content Model

Use for Gutenberg/editor questions.

The starter provides curated Gutenberg, not full site building.

Use Gutenberg for:
- editorial content
- articles
- generic flexible pages

Use structured fields/CPTs in client projects for:
- services
- fleet
- testimonials
- team
- projects
- repeatable entities

Do not add permanent project CPTs to the starter theme.

When a project curates blocks, preserve incoming `false`, intersect incoming
arrays, and preserve the WooCommerce Product policy by default.
