## 6. Technical SEO status

- **Canonical:** self-referencing on all 15 pages; no cross-language canonical.
- **hreflang (Polylang):** en/pl/ru reciprocal on every group. **No `x-default`** — not added (no architectural reason; default language is hidden-prefix `en`, so adding it is optional).
- **Sitemap (Rank Math):** index → `page-sitemap.xml`, 15 URLs (5 EN, 5 PL, 5 RU), no noindex page, no sample page, canonical = sitemap URL. Only a page sitemap exists (no posts/terms). HTML sitemap and authors sitemap enabled but empty/unused. Local host is `http://venix-concierge.local`; non-www HTTPS production host **to be re-verified after deployment**.
- **robots.txt:** WP default (`Disallow /wp-admin/`, sitemap line) — no blocking of public pages.
- **Duplicates:** none (one title/description/canonical/OG set per page).
- **Schema now:** Home (all 3 languages): `Organization` (name only) + `WebSite` + `WebPage`. Inner pages: none. The `WebSite` `SearchAction` (no site search exists) is removed by a project-core filter.
- **Internal linking:** each language links only to its own language except the language switcher and hreflang. Home → Services/Fleet/About/Contact present in header, footer and body; `/services/` also has normal (non-fragment) links, so the fragment-only concern does not apply. No orphans among the 15 pages. Sample page and draft Privacy Policy are unlinked (by design).
- **Author archive:** `/author/admin/` already `noindex`.
